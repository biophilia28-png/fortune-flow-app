# 운세플로우 fortune-flow-app

통계 기반 사주 운세 앱 MVP입니다.

## 포함 기능
- 오늘의 운세 흐름
- 대운/세운/월운/일운/시운 점수
- 12지신 방향운
- 통계 피드백
- 필수 공지 / 개인정보 안내
- 관리자 통계 대시보드
- 스토어 등록용 6개 화면 미리보기

## 실행
```bash
npm install
npm run dev
```

## Vercel 배포
GitHub 저장소에 업로드 후 Vercel에서 Import Project 하면 됩니다.

## 출시 전 추가 필요
- 실제 사주 계산 엔진
- Firebase 사용자 통계 저장
- 관리자 로그인 보호
- 위치 권한 처리
- 개인정보처리방침 URL
- 이용약관 URL
- 문의 이메일
